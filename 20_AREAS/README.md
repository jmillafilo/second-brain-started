# 🌱 Carpeta 20_AREAS (Áreas de Responsabilidad)

Esta carpeta almacena todas tus facetas de vida y responsabilidades continuas.

### Características de un Área:
1. **No tienen fecha de término**: Se mantienen de por vida o mientras mantengas ese rol (ej: *Salud*, *Finanzas*, *Familia*, *Mascotas*, *Hogar*).
2. **Definen un estándar de calidad**: Tu meta es mantener estas áreas saludables y ordenadas a través de hábitos y rutinas.
