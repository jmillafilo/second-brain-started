# 📚 Carpeta 30_RESOURCES (Recursos y Referencias)

Esta carpeta es tu biblioteca personal de conocimiento.

### Características de un Recurso:
1. **Es material de consulta o interés continuo**: Temas sobre los que te gusta aprender, coleccionar o investigar.
2. **No requiere acción inmediata**: A diferencia de los proyectos o áreas, no hay una obligación de mantenerlo al día; es un repositorio de referencia cuando lo necesites.

---

## 📂 Carpetas y Temas Sugeridos
- `Notas_y_Lecturas/`: Resúmenes de libros, artículos web destacados, conferencias.
- `Herramientas_y_Software/`: Listados de apps, prompts útiles, snippets de código, comandos.
- `Recetas/`: Preparaciones culinarias, guías de cocina.
- `Glosarios_y_Cheatsheets/`: Fichas de referencia rápida.
